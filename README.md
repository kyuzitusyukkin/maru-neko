# まるねこ

まるまった猫を落として、くっつけて、大きな猫に育てよう。

同じ猫どうしがくっつくと、1つ大きな猫に育ちます。育った猫がそのままほかの猫とくっつくとコンボになって、ボーナス点がもらえます。いちばん大きいのはキングキャット。点線より上に猫がはみ出したままになると、おしまいです。

遊ぶ：https://kyuzitusyukkin.github.io/maru-neko/
